使用说明

三步把飞牛 NAS 接入 Cloudflare Tunnel

操作步骤
点「登录 Cloudflare 并生成」，在弹出的官方页面登录（没有账号先免费注册）。
登录后软件会自动勾选权限并创建令牌，完成后回到概览页。
复制 API 令牌（需要时再复制账户 ID），粘贴到飞牛 fnOS 的 Kay-cftunnle 应用里保存即可。
常见问题
登录后没有自动继续？

在页面上手动点「继续以显示摘要」→「创建令牌」，软件会自动读取生成的令牌。

令牌丢了怎么办？

Cloudflare 不会再次显示旧令牌。点「重新生成」创建新的，再到 Cloudflare 控制台删除旧的。

想换一个 Cloudflare 账号？

右侧「Cloudflare 账号」里点「切换账号」，退出后用新账号登录。

提示缺少 WebView2？

到微软官网安装「Microsoft Edge WebView2 Runtime」，Windows 10/11 一般已自带。
